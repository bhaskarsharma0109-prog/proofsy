# Proofsy Design System

## Core Strategy
- **Aesthetic**: Technical Precise / Financial Dashboard.
- **Rhythm**: Compact, data-dense layouts with clear visual hierarchy.
- **Micro-interactions**: Smooth transitions (200ms), number animations, and status indicators.

## Colors (OKLCH)
- **Primary**: `oklch(55% 0.18 250)` (Deep Blue - #2563EB)
- **Secondary**: `oklch(65% 0.15 250)` (Light Blue - #3B82F6)
- **CTA**: `oklch(65% 0.2 45)` (Orange - #F97316)
- **Background**: `oklch(98% 0.01 250)` (Off-white tinted with blue)
- **Text**: `oklch(25% 0.02 250)` (Dark charcoal tinted with blue)

## Typography
- **Headings/UI**: Fira Sans
- **Data/Metadata/Codes**: Fira Code (Technical, precise feel)
- **Scale**: 1.25 ratio (Major Third)

## Components
- **Verification Badge**: High-contrast, precise borders (1px solid), status-colored indicators.
- **Certificate Preview**: Real-time rendering, auto-scaling text logic.
- **Dashboard Cards**: Minimum padding 1.5rem, no side-stripe borders, subtle shadows.

## Verification Checklist
- [ ] OKLCH color usage.
- [ ] No side-stripe borders.
- [ ] No gradient text.
- [ ] Fira Code for all verification codes and data points.
- [ ] High contrast (WCAG AAA for data).
